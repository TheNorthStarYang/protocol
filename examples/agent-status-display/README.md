# Agent Status Display

## What it does

Default SDK example for AI coding workflows.

It demonstrates:

- key callbacks
- toggle switch state
- AI running / waiting / done state display
- OLED feedback
- LED feedback

## Build

```powershell
powershell -ExecutionPolicy Bypass -File .\sdk\build\build.ps1
```

or:

```powershell
powershell -ExecutionPolicy Bypass -File .\sdk\build\build.ps1 -Example agent-status-display
```

## Expected effect

The keyboard shows AI workflow state on OLED and LEDs.

Buildable default example.
