# Toggle Switch Demo

## What it does

Demonstrates reacting to toggle switch up/down changes.

## SDK modules

- `sdk/toggle/`
- `sdk/core/include/ahakey_lever.h`

## Build

```powershell
powershell -ExecutionPolicy Bypass -File .\sdk\build\build.ps1 -Example toggle-switch-demo
```

## Expected effect

The device changes display or light behavior when the toggle switch changes.

## Status

Buildable sample. Behavior should be refined for a specific workflow before production use.
