# Toggle Switch SDK

Use the toggle switch callback to react to physical lever changes.

Related headers:

```text
sdk/core/include/ahakey_lever.h
```

Expected states:

```text
AHAKEY_LEVER_UP
AHAKEY_LEVER_DOWN
AHAKEY_LEVER_UNKNOWN
```

Typical uses:

- manual approval / auto approval
- workflow mode switch
- AI agent state switch
