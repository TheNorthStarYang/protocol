# Buttons SDK

Button customization module.

Public APIs are declared in:

```text
../ahakey_core/include/ahakey_key.h
../ahakey_core/include/ahakey_hid.h
```

Supported user-facing events include key down, key up, short press, double click, long press, and hold.

The small system/power button is not part of the public button customization API in the first SDK release.
